# Backend

This folder contains the FastAPI backend for the AI-Based Warehouse Automation & Digital Twin System.

## Tech Stack

- FastAPI
- SQLAlchemy
- PostgreSQL
- Alembic
- YOLOv8 Integration
- Scikit-learn

## Setup

```bash
pip install -r requirements.txt
```

Run the server:

```bash
uvicorn app.main:app --reload
```
